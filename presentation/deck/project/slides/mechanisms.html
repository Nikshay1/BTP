Three mechanisms, written as plain algorithms

Ant colony

Reinforced search

Agents build solutions step by step. Steps on paths that passed the checks get more weight (“pheromone”); weights evaporate over time.

Controls: no deposit, no evaporation, uniform choice

Honeybee swarm

Evidence and inhibition

Scouts propose answers, recruit others to the ones they trust, and send stop signals to rivals. The swarm commits at a quorum.

Controls: no stop signal, majority vote with the same calls

Octopus

Bounded local work

The coordinator hands a bounded job to an “arm” that acts and observes on its own, and reports back only the result.

Controls: per-step reporting, plan-then-execute

Every mechanism is defined by what it computes. Each has plain counterparts without its biological parts, so we can tell the mechanism apart from extra compute. Crow (tool planning) and starfish (recovery) follow in Phase 2.

Speaker: Madan. We implemented three mechanisms first. The ant colony builds a solution step by step; steps that led to accepted solutions get more weight, and weights fade over time. The honeybee swarm lets scouts propose answers, recruit others, and stop rivals with stop signals, until a quorum agrees. The octopus hands a bounded job to an arm that works on its own and only reports the result. Following the skeptical literature, we write each one as an ordinary algorithm, and we built plain versions without the biological part: for example, bee without stop signals, or a majority vote with exactly the same number of calls. If the mechanism wins only because it uses more compute, these controls will show it.
