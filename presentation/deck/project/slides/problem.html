The problem: one way of working for every subtask

LLM multi-agent systems fix their coordination pattern before they see the task: a debate, a pipeline of roles, or a manager with workers.

Real tasks are mixed. One part needs a search over many paths, another needs several opinions reconciled, a third is routine work for one worker.

Using one pattern everywhere pays for messages and tokens that do not improve the answer.

+80.8% to −70.0%

Change against a single agent across tasks, same model and compute (Kim et al., 2026). Coordination helps only when it fits the task.

14 failure modes

Found in 1,600+ traces of seven frameworks; many come from system design and coordination, not the model (Cemri et al., NeurIPS 2025).

Speaker: Aryan. Today most multi-agent systems built on large language models choose one way for the agents to work together, and they use it for the whole task. But a task has different parts. Some parts need searching, some need a vote, and some are easy and need just one worker. A controlled study by Kim and others in 2026 compared a single agent with four multi-agent designs under the same model and compute. The change ranged from plus 81 percent on one task to minus 70 percent on another. Cemri and others studied more than 1,600 failed runs and found fourteen failure modes, many caused by the coordination design itself. So the way agents coordinate should match the work.
